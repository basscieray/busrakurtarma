# Büşra'yı Kurtarıyorum

Mario tarzı, telefonda ve bilgisayarda oynanan küçük bir macera oyunu.

## Oynanış
- Bilgisayar: ok tuşları / A D yürü, Boşluk zıpla, X vur, C veya ↓ kalkan
- Telefon: ekrandaki düğmeler (yatay tutman önerilir)

## GitHub Pages ile yayınlama
1. GitHub'da yeni bir **public** repo aç.
2. Bu klasördeki tüm dosyaları repoya yükle (index.html en dışta olmalı).
3. Settings → Pages → Source: **Deploy from a branch** → Branch: **main** / **(root)** → Save.
4. 1-2 dakika sonra adres hazır: `https://KULLANICI-ADIN.github.io/REPO-ADI/`
